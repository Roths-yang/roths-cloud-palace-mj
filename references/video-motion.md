# 图生视频动态提示词

## 输入与目标

必须先看当前定稿图，再识别前景、中景、远景、人物数量与身份、主体轮廓、光线、水流以及可供视差的层次。用户给过的具体运镜、动作和失败反馈优先于这里的默认建议。只要求动态提示词时，不替用户改图或安排剪辑。

每张图通常写一段可直接复制的中文提示词。若用户指定时长、比例、字数或模型，按指定值写；未指定时可采用约5秒、16:9、单镜头、缓慢稳定的表达，不把这些数值写成永久硬性规则。

## 先锁画面，再给运动

1. 记录视觉锚点：门洞、楼阁、山峰、桥梁、岩层、月轮、水平冰崖或地平线。其形状和相互位置保持可信。
2. 只选择一种主要镜头运动：横移、前推、拉远、轻微升高、缓慢绕转或固定镜头。若用户明确要求组合运动，交代主次，并保证总量很小。
3. 明确前景与远景的相对运动。镜头向右横移时，近景通常向左产生视差；向左时相反。远景可相对固定，但不是把所有岩石、树枝和人物锁死。
4. 再赋予环境运动：云雾绕行、瀑布下落、水面微波、草浪、花叶、雪粒、衣袖。让主运动可读，其余低频陪衬。
5. 人物动作只写一个连续行为：静立后抬头、缓慢行走、迈一小步后站定、自然登阶、平稳飞行等。保留原图人数、服装、位置关系和大致屏幕尺寸。多人或多头神兽动作可错开，避免机械同步。
6. 对易失控处给少量具体限制，优先写正向轨迹与终点。例如“缓慢靠近桥前悬停”，比反复堆砌“不得飞过桥”更易执行；测试已出现的光束、复制人物等可补明确禁令。

## 运镜选择

| 画面结构 | 常用主运镜 | 注意 |
|---|---|---|
| 道路、长桥、石阶、长廊、明确消失点 | 低机位缓慢前推 | 远端主体维持轮廓；人物不因镜头前推而突然放大 |
| 前景框景与远景主体分明 | 极缓慢横移 | 近景产生视差，远景主体位置相对稳定 |
| 完整的对称、圆门、月轮或巨型宝塔 | 极微横移或固定镜头 | 维持几何中心，不让圆形、轴线扭曲 |
| 草原通向山体巨构 | 缓慢拉远或低机位横移 | 拉远时逐渐显露地表连续关系 |
| 高位俯瞰、悬崖、瀑墙 | 轻微升高、横移或固定 | 选一种最能显示深渊尺度的运动 |
| 洞穴与地缝 | 缓慢前推、横移或极轻绕转 | 岩层可产生视差，洞口及中央岩峰形态稳定 |
| 水面平视峡谷 | 贴水面平稳跟随 | 水下石块、水平线、水体清澈度保持连续 |

## 特别容易出错的动态

- 飞行与起跳：保留自然身体姿态、速度与距离变化；默认无光束、粒子、尾焰或法术特效。若画面有桥、门、崖等边界，写明飞向哪里、停在哪里，不任其穿越全部空间。
- 登阶：唯一人物从原位置走到台阶并连续上行；镜头若横移或固定景别，人物屏幕尺寸变化须平缓。人物不能在台阶上另生一个副本。
- 冰面与水平瀑沿：可让雾与倒影变化，固定冰崖边缘的水平连续性，不让冰层熔化、弯曲或崩塌。
- 山体拟态：岩石可像猿首或神兽轮廓，但这种轮廓本身不张嘴、不眨眼、不转头。真实神兽则可以动，需守住头数、翅膀、尾羽与躯干连接。
- 纯自然场景：重点放在云雾、透光、植被与水流，不因“仙宫”主题自动生成建筑。

## 提示词结构

`原图构图与机位 → 唯一主运镜和速度 → 近中远景的视差或稳定锚点 → 人物原有数量及一个连续动作 → 云、水、草、光等环境运动 → 少量针对性的稳定性限制。`

不要把所有镜头都写成同一种运镜，也不要一律要求女性行走。原图没有人物时不增加人物；有人但性别不明时不推断。保持建筑庄严、主体身份与原图一致。
