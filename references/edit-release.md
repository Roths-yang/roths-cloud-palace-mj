# 剪辑顺序、封面与发布文字

## 排序依据

先盘点用户最后采用的镜头，尊重已删除或移组的片段。若能访问音乐，听其起伏；只有文件名或时长时，不臆测精确节拍。对每张图简记：主色、主体、视点高度、运动方向、情绪强度、文化信息与画面是否有建筑。

优先考虑三种连接：

1. **形状接力**：洞口到月门、月轮到圆形天门、长阶到云桥。
2. **色彩接力**：红色神兽到红花海，米白宫墙到雪岭、冰原。
3. **空间接力**：地缝仰望、走出峡谷、登临云海、抵达天城；可用相反方向制造转折。

排序可因用户审美改变；能解释每一处转场即可。纯自然镜头可用作开场、转场或尾声，但若系列以建筑世界观为主，先建立建筑也常有效。不要把某一次成片顺序写成万能模板。

节奏上给奇观留展示时间，静镜头提供呼吸。总音乐比所有视频片段总和短时，截取每条最有效的动作，不机械播放满时长。封面不必是第一镜，只需能概括系列并抓住注意力。

## 封面

候选图按以下维度判断：缩略图可读的主体轮廓、系列代表性、色彩冲击、文化或世界观辨识度、人物与主体不被标题遮挡。封面标题可为四字或更短，但并非硬性字数；标题颜色和位置依据亮暗区与留白决定。

## 发布文案

- 先确认用户发布平台、成片实际镜头和是否需要时令关键词。
- 小红书标题可更明确地包含可搜索的主题词；视频号标题可更简洁、诗意。实际表达由用户作品和语气决定，不预设平台算法偏好或保证爆款。
- 文案短句为主，选2–4个具有辨识度的画面串联，不逐镜报菜名。真实地标、文化来源与仙界想象明确区分。
- 标签围绕内容、风格、制作方式和时令选择；用户要求10个就给恰好10个，不编造未出现的地点或节日。
